no# Project Rules

**IMPORTANT: Always use the pyenv environment for this directory (Python 3.11) when running code, tests, or linting tools. Prepend commands with `pyenv exec ` or activate the environment first.**

1. At the end of a task, execute `flake8` and ensure there are no errors. If there are, fix them.
2. At the end of a task, run all unit tests and ensure there are no failures. If there are, fix them.
3. When running the code or tests, make sure you're using the pyenv environment for the directory.
4. Do not add tests and then skip them.
5. No test failures are acceptable.
6. Never do imports within functions; always import at the top of files.
7. Unused imports are not permitted.
8. Nothing should come between import statements, including blank lines and non-import code.
